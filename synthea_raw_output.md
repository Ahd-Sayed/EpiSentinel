# synthea_raw_output

Raw output generated with Synthea for a population of 100,000 synthetic patients. This is the unprocessed source data used to build the EpiSentinel master dataset.

- **Files:** `patients.zip`, `encounters.zip`, `conditions.zip`, `organizations.zip`
- **Download from Kaggle:** https://www.kaggle.com/datasets/ahdsayedattia/synthea-raw-output

All records are synthetic and contain no real patients.
