# master_dataset

The full EpiSentinel master dataset: synthetic hospital-visit records for African cities, built from Synthea and calibrated with historical outbreak scenarios.

- **File:** `master_dataset.zip` (about 525 MB)
- **Download from Kaggle:** https://www.kaggle.com/datasets/ahdsayedattia/episentinel-synthea-to-african-data

The file is hosted on Kaggle because it exceeds GitHub's 100 MB file-size limit.

Built from the raw Synthea output: https://www.kaggle.com/datasets/ahdsayedattia/synthea-raw-output
